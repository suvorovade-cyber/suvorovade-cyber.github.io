## С чего всё началось

Про Markdown я узнала, когда начала работать с Hugo и GitHub. Оказалось, что писать тексты в нём гораздо быстрее, чем в обычном редакторе.

Раньше я тратила время на то, чтобы выставить заголовок жирным, выровнять списки, вставить ссылку. В Markdown всё это делается парой символов — и не нужно отвлекаться от содержания.

## Что мне нравится

**Простота.** Синтаксис можно выучить за 10 минут. При этом текстовый файл остаётся читаемым даже без обработки — его можно открыть в любом блокноте.

**Универсальность.** Markdown поддерживается везде: в мессенджерах (Telegram, Discord), на GitHub, в заметках (Obsidian, Notion), в блогах на Hugo.

**Контроль версий.** Обычный текст удобно отслеживать в Git. В отличие от бинарных форматов вроде .docx, здесь видно каждое изменение.

## Как я использую

В основном для:
- постов на этом сайте
- оформления README на GitHub
- заметок в Obsidian
- комментариев и issue на GitHub

## Итог

Markdown — это инструмент, который экономит время. Он не пытается быть красивым редактором, он просто даёт возможность быстро оформить текст. Для меня это стало привычкой, и обратно уже не хочется.

Попробуйте — возможно, вам тоже зайдёт.
