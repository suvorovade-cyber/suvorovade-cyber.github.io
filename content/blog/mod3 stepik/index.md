## Текстовый редактор vim
 
![](image/Рис.1.png)
 
Правильный ответ - ":", затем "q", затем "Enter". В нормальном режиме vim команды вводятся после двоеточия, :q завершает редактор.
 
![](image/Рис.2.png)
 
Правильные ответы: в строке 5 "больших слов" (WORD); чтобы попасть в конец строки, нужно одинаковое число нажатий W и w; нажимая только на W, нельзя переместить курсор на "."; в строке 9 "слов" (word). WORD разделяются только пробелами, а слова (word) дополнительно разбиваются знаками пунктуации.
 
![](image/Рис.3.png)
 
Правильные ответы: d2wwifour four <Esc> и xxxxxxxxxyywP. В первом варианте удаляются два слова, затем вставка "four four". Во втором стираются первые девять символов, копируется слово four и трижды вставляется.
 
![](image/Рис.4.png)
 
Правильный ответ - :%s/Windows/Linux/. Команда :%s заменяет первое вхождение в каждой строке, что и требуется в условии.
 
![](image/Рис.5.png)
 
Правильные ответы: внизу редактора появляется надпись -- VISUAL --; можно использовать команды перемещения; режим открывается из нормального режима по нажатию v. Режим выделения не открывается из любого режима и не требует :q для выхода.
 
## Скрипты на bash: основы
 
![](image/Рис.6.png)
 
Правильный ответ - только из набора C. Каждая оболочка имеет свою историю команд, вложенная оболочка не наследует историю родительской.
 
![](image/Рис.7.png)
 
Правильный ответ - /home/bi/file1.txt. Скрипт сначала переходит в /home/bi/ и создаёт файл там, затем переходит в Desktop, но файл остаётся в /home/bi/.
 
![](image/Рис.8.png)
 
Правильные ответы: variable_123, VARIable, variable. В bash имя переменной может содержать буквы, цифры и подчёркивание, но не должно начинаться с цифры.
 
![](image/Рис.9.png)
 
Правильный код: echo "Arguments are: \$1=$1 \$2=$2". Первый аргумент подставляется как $1, а \$1 выводится как литерал $1.
 
## Скрипты на bash: ветвления и циклы
 
![](image/Рис.10.png)
 
Правильные ответы: !(4-le 3) и 5-ge 5. Первое выражение означает "не (4 <= 3)", что всегда истинно, второе "5 >= 5" также всегда истинно. Остальные зависят от аргументов или переменных.
 
![](image/Рис.11.png)
 
Правильный ответ - сначала four, потом four. При var=3 выполняется блок else (four), при var=5 также выполняется else, так как ни одно из условий не срабатывает.
 
![](image/Рис.12.png)
 
Правильный код проверяет первый аргумент: 0 → No students, 1 → 1 student, 2-4 → "$1 students", 5 и больше → A lot of students.
 
![](image/Рис.13.png)
 
Правильный ответ - 5 раз "start" и 4 раза "finish". Цикл перебирает элементы a, b, c_d. Для a (код символа 97) условие $str > "c" ложно, выводятся start и finish. Для b (98) также ложно. Для c_d (99) условие истинно, выводится только start, continue пропускает finish.
 
![](image/Рис.14.png)
 
Код реализует бесконечный цикл: запрашивает имя и возраст, при пустом имени или возрасте 0 выходит с "bye", иначе выводит группу (child, youth, adult).
 
## Скрипты на bash: разное
 
![](image/Рис.15.png)
 
Правильные ответы: let a=a+b, let "a+=b", let a=$a+$b. Команда let выполняет арифметику, остальные варианты приводят к строковой конкатенации.
 
![](image/Рис.16.png)
 
Правильный ответ - /home/bi. Обратные кавычки выполняют pwd после cd /home/bi/, поэтому выводится новая директория.
 
![](image/Рис.17.png)
 
Правильные ответы: сначала запустить program, затем if [[ $? -eq 0 ]]; if `program > some_file.txt`. Первый способ проверяет код возврата через $?, второй перенаправляет stdout в файл, оставляя в if код возврата.
 
![](image/Рис.18.png)
 
Правильный ответ - counters are and 110. Переменная c1 объявлена как local, поэтому вне функции она пуста. c2 глобальна и после вызовов с параметрами 1..10 даёт сумму 1*2+2*2+...+10*2 = 110.
 
![](image/Рис.19.png)
 
Функция gcd реализует алгоритм Евклида вычитанием. Основной цикл читает пары чисел, при пустой строке выводит bye и завершается.
 
![](image/Рис.20.png)
 
Скрипт читает выражение, при вводе "exit" выходит с "bye", иначе вычисляет через $(( )) и выводит результат или "error" при ошибке.
 
## Продвинутый поиск и редактирование
 
![](image/Рис.21.png)
 
Правильные ответы: Star_Wars.avi, STARS.txt, stardust.mpeg. Опция -iname игнорирует регистр, -name чувствительна, поэтому эти файлы соответствуют шаблону только при -iname.
 
![](image/Рис.22.png)
 
Правильный ответ - только последнее утверждение: "Если заменить -name на -path, то результат поиска иногда может остаться таким же". -path проверяет весь путь, а не только имя файла, но при поиске в текущей директории без подпапок они могут совпасть.
 
![](image/Рис.23.png)
 
Правильный ответ - все кроме file3. Команда ищет на глубине от 2 до 3: file1 находится на глубине 2 (dir1/file1), file2 на глубине 3 (dir1/dir2/file2), file3 на глубине 4 (dir1/dir2/dir3/file3) – не подходит.
 
![](image/Рис.24.png)
 
Правильный ответ - grep -C 1 "word" file.txt > results.txt. Опция -C 1 выводит найденную строку и по одной строке контекста до и после, то есть три строки на каждое вхождение.
 
![](image/Рис.25.png)
 
Правильные ответы: 1 (I prefer Kubuntu), 3 (Lubuntu is better than Ubuntu), 4 (Linux is not always Ubuntu), 6 (Mac OS X, Windows, Ubuntu). Регулярное выражение ищет строки, оканчивающиеся на "buntu" с возможным префиксом из букв x,k,l,X,K,L и буквой u/U.
 
![](image/Рис.26.png)
 
Правильный ответ - каждая строчка будет выведена два раза. Без -n sed по умолчанию выводит все строки, а команда p печатает строку дополнительно.
 
![](image/Рис.27.png)
 
Правильный ответ - sed 's/ [A-Z]([A-Z])+ / abbreviation /g' input.txt > edited.txt. Пробелы вокруг шаблона и замены сохраняют количество пробелов, а группировка ([A-Z])+ обходит ограничение проверяющей системы на квантификаторы.
 
## Строим графики в gnuplot
 
![](image/Рис.28.png)
 
Правильный ответ - -p, --persist. Опция persist предотвращает закрытие окон с графиками после выхода из gnuplot.
 
![](image/Рис.29.png)
 
Правильный ответ - название – первое значение из второго столбца, нарисовано 9 точек. Установка autotitle columnhead использует первую строку данных как заголовок, но эта строка не рисуется.
 
![](image/Рис.30.png)
 
Правильный ответ - set xtics ("point 1, value ".x1 x1, "point 2, value ".x2 x2, "point 3, value ".x3 x3). Конкатенация строк через точку объединяет текст с значением переменной.
 
![](image/Рис.31.png)
 
Изменённый файл: a=a+1; zrot=(zrot+350)%360; set view xrot,zrot; splot -x**2-y**2; pause 0.1; if (a<50) reread. Знак минус в splot даёт зеркальное отражение, изменение угла вращения на 350° (вместо 10°) меняет направление, а pause 0.1 (вместо 0.2) ускоряет вращение вдвое.
 
## Разное
 
![](image/Рис.32.png)
 
Правильные ответы: chmod ug+w file.txt; chmod u+x file.txt и chmod a+wx file.txt; chmod o-wx file.txt; chmod g-x file.txt. Обе последовательности дают права rwxr-xr--.
 
![](image/Рис.33.png)
 
Правильные ответы: sudo chown user dir и sudo chmod o+w dir. Первая команда делает пользователя владельцем, вторая даёт право на запись всем остальным, что позволяет пользователю группы group создать файл.
 
![](image/Рис.34.png)
 
Правильные ответы: количество строк, количество символов, количество слов. Команда wc с опциями -l, -c/-m, -w выводит эти характеристики.
 
![](image/Рис.35.png)
 
Правильный ответ - du -h -s (или du -sh). Опция -h выводит размер в удобочитаемом формате, -s суммирует размер текущей директории без вывода поддиректорий.
 
![](image/Рис.36.png)
 
Правильный ответ - mkdir dir{1..3} (или mkdir dir{1,2,3}). Фигурные скобки в bash раскрываются в список аргументов, что даёт самую короткую команду.
