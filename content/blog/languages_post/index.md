## Python

Самый популярный язык в научной среде. Причины:
- огромное количество библиотек (NumPy, SciPy, Matplotlib, Pandas, Scikit-learn)
- низкий порог входа
- активное сообщество

Главный минус — чистая медленность интерпретатора, но векторизованные библиотеки на C/C++ эту проблему смягчают.

## R

Специализированный язык для статистики и анализа данных. Сильные стороны:
- пакетная система CRAN (тысячи готовых решений)
- великолепная встроенная визуализация (ggplot2)
- удобная работа с датафреймами

Вне статистики используется редко.

## Julia

Молодой язык, созданный специально для научных вычислений. Ключевая особенность — скорость, сопоставимая с C, при синтаксисе, близком к Python. Решает проблему «двух языков» (прототип на Python, боевая версия на C++). Минус — молодая экосистема.

## MATLAB

Классика инженерных расчётов и моделирования. Плюсы:
- мощная работа с матрицами как с базовым типом данных
- огромный набор тулбоксов под конкретные задачи (сигналы, управление, оптимизация)

Минусы: платный и дорогой, синтаксис устаревает.

## Итог

Выбор зависит от задачи. Python — универсальный солдат. R — статистика и графики. Julia — туда, где нужна скорость. MATLAB — legacy в инженерии и обороне.
